## 🚀 طريقة الرفع على الاستضافة المجانية

### 1️⃣ Netlify (الأسهل)
1. اذهب إلى [netlify.com](https://netlify.com)
2. سجل حساب مجاني
3. اضغط "Add new site" → "Deploy manually"
4. اسحب ملف ZIP مباشرة أو ارفع الملفات المستخرجة
5. ستحصل على رابط مجاني مثل: `https://mahanti-abc123.netlify.app`

### 2️⃣ Vercel
1. اذهب إلى [vercel.com](https://vercel.com)
2. سجل بحساب GitHub
3. ارفع الملفات عبر "Upload"
4. ستحصل على رابط مجاني

### 3️⃣ GitHub Pages
1. أنشئ repository جديد على GitHub
2. ارفع الملفات
3. اذهب إلى Settings → Pages
4. اختر Branch: main → Folder: root
5. ستحصل على رابط مثل: `https://username.github.io/mahanti-app`

### 4️⃣ 000webhost / InfinityFree
1. سجل حساب مجاني
2. اذهب إلى File Manager
3. ارفع الملفات إلى مجلد `public_html`
4. ستحصل على رابط مجاني
