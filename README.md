# 🛠️ مهنتي V2 - دليل المهن الحرفية العالمي

**Mahanti V2 - Global Trades Directory**

تطبيق ويب كامل بـ **Backend حقيقي** يدعم **35+ بلد** و**لغتين (عربي/إنجليزي)** و**3 طرق توثيق**.

## ✨ المميزات الجديدة في V2

- 🌍 **35+ بلد** - السعودية، مصر، الأردن، الإمارات، قطر، الكويت، البحرين، عمان، العراق، سوريا، لبنان، فلسطين، اليمن، السودان، ليبيا، الجزائر، المغرب، تونس، تركيا، باكستان، الهند، إندونيسيا، بنغلاديش، نيجيريا، أمريكا، بريطانيا، ألمانيا، فرنسا، إيطاليا، إسبانيا، البرازيل، الصين، اليابان، روسيا، جنوب أفريقيا، أستراليا، كندا...
- 🌐 **ثنائي اللغة** - العربية + الإنجليزية (كامل)
- 📱 **توثيق متعدد** - واتساب أو SMS أو بريد إلكتروني
- 🏙️ **مدن تلقائية** - تتغير حسب البلد المختار
- 📞 **أكواد دولية** - يدعم جميع أكواد البلاد العالمية
- ✅ **Backend حقيقي** - Node.js + Express + قاعدة بيانات JSON
- 🔍 **بحث ذكي** - حسب البلد والمدينة والمهنة والاسم
- 📊 **إحصائيات حية** - تتحدث مع كل تسجيل جديد
- 💚 **مجاني 100%** - لا رسوم ولا عمولات

## 🚀 طريقة التشغيل

### 1️⃣ تثبيت المتطلبات
```bash
cd mahanti-v2
npm install
```

### 2️⃣ تشغيل التطبيق
```bash
npm start
```

### 3️⃣ فتح المتصفح
```
🌐 http://localhost:3000
```

## 🌐 API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/countries` | جميع البلدان |
| GET | `/api/countries/:code` | بلد محدد |
| GET | `/api/translations/:lang` | الترجمات (ar/en) |
| GET | `/api/workers` | جميع العمال |
| GET | `/api/workers/search` | البحث المتقدم |
| POST | `/api/workers` | تسجيل عامل جديد |
| POST | `/api/verify/send` | إرسال OTP |
| POST | `/api/verify/check` | التحقق من OTP |
| GET | `/api/stats` | الإحصائيات العامة |

## 🚀 الرفع على Render.com (مجاني + يعمل 24/7)

3. الإعدادات:

   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
4. Create Web Service ✅
